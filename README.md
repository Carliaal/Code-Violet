# Code-Violet
Platform for mapping, analyzing, and raising awareness about violence against women.

---

![logo-code-violet](/docs/Cinta%20de%20conciencia%20morada.png)

# English

This project is a web application focused on the analysis and visualization of data related to sexual violence against women. Its main goal is to raise awareness, provide insights, and support a better understanding of this social issue through data.

By transforming open datasets into interactive and accessible visualizations, the application aims to make information more transparent and useful for education, research, and decision-making. It may also include features such as geographic mapping of incidents or resources, helping to highlight patterns and support prevention efforts.

This project is developed with a data-driven approach, prioritizing clarity, accessibility, and ethical use of sensitive information.

# Español

Este proyecto es una aplicación web centrada en el análisis y la visualización de datos relacionados con la violencia sexual contra las mujeres. Su objetivo principal es concienciar, aportar información relevante y facilitar una mejor comprensión de esta problemática social a través de los datos.

Mediante la transformación de datasets abiertos en visualizaciones interactivas y accesibles, la aplicación busca hacer la información más transparente y útil para la educación, la investigación y la toma de decisiones. También puede incluir funcionalidades como mapas geográficos de incidentes o recursos, ayudando a identificar patrones y apoyar la prevención.

El proyecto se desarrolla con un enfoque basado en datos, priorizando la claridad, la accesibilidad y el uso ético de información sensible.
